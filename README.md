# CHERD

A chord sequencer: your right hand plays roots, each becomes the chord that note has in your key and scale; your left
hand bends it into any flavor; a genre (Flow) dresses the chords you leave alone. Strum, comp (incl. la pompe), an
arpeggiator, and chord names written out fakebook style.

CHERD lives on several instruments. Each has its own folder:

| Instrument | Folder | State |
| --- | --- | --- |
| **OP-1 Field** | [`field/`](field/) | `cherd.pack` for OS 1.7.3+0 with open-field: an eighth sequencer in TE's menu. Read the warning there first |
| OP-XY | `opxy/` | to come here; CHERD started on the OP-XY |
| MPC Sample | `mpc-sample/` | to come here |
